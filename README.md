# 🍺 Last Call HQ — Oxford Edition

A dumb-fun drink + BAC tracker for the boys. One file, no backend, works great on phones.

## What it does
- Tap your name, set weight + M/F once (needed for the BAC math)
- Log drinks with one tap (beer, Natty, tall boy, shots, doubles, jungle juice...)
- Live estimated BAC that rises as you log and slowly drops over time
- Funny ranks (Nicely Buzzed -> Menace to Uptown -> Blackout Wizard)
- Crew-wide achievements to chase
- Leaderboard with medals
- Reset the Night button

Data saves in each phone's browser (localStorage). It does NOT sync between phones — everyone tracks on their own device, which is the point.

## The important part
The BAC number is a rough Widmark estimate for laughs. It is not accurate and never a green light to drive. If you're driving, it's 0.00. Water, rides, look out for each other.
